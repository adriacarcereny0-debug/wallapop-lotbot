# Tu licencia de LOT Bot

**Activar.** Al abrir LOT Bot (con Wallapop real) aparece «Activa tu licencia».
Escribe la clave que te llegó (`LOTB-XXXX-XXXX-XXXX`) y pulsa **Activar
licencia**. También desde **Configuración → Licencia**.

**Sin licencia** LOT Bot se abre igual, con todos tus datos, pero no publica ni
cambia nada en Wallapop. El **modo DEMO** es gratis.

**Sin Internet** sigue funcionando hasta 3 días. Conéctate antes y sigue solo.

**Si caduca o se suspende**, el anuncio que se esté publicando termina y la
cola se pausa. Al renovar, la cola continúa sola. No se borra nada.

**Cambiar de ordenador**: Configuración → Licencia → **Desvincular este
ordenador**, y actívala en el nuevo (plan mensual: 1 ordenador; anual: 2).
